## 범위 밖

| 기능 | 사유 |
|---|---|
| **1:1 문의** (`/inquiries`, `/mypage/inquiries`, `/mypage/contact`) | 기존 서비스에서 **마이페이지 메뉴가 주석 처리되어 비활성** 상태다. 현재 문의는 외부 폼(Google Forms)으로 대체되어 있다. 이번 프로젝트는 구조 정리가 목적이므로 **비활성 기능을 되살리지 않는다** |

## 전제

- 상위 문서: [PRD](../PRD.md) · [데이터 모델 명세](../데이터-모델-명세.md)
- **모든 권한 판정은 `00-관계-판정`을 따른다.** 개별 스펙은 이를 재정의하지 않는다.
- 사용자 유형(`role`) 개념은 존재하지 않는다. 스펙 어디에도 등장하지 않아야 한다.

## 확정된 정책

구현 전 결정이 필요했던 6건은 모두 확정되었다. **미결 항목 없음.**

| # | 항목 | 결정 | 근거 문서 |
|---|---|---|---|
| 1 | **동점 시 낙찰자** | 총점이 같으면 **먼저 작성한 사연** 우선 | [F5](./F5-낙찰.md) 3.2.1 |
| 2 | **포인트 정산** | 낙찰자 차감 확정 → **주최자에게 이전**, 미낙찰자·유찰 시 **전액 반환** | [F5](./F5-낙찰.md) 3.5 |
| 2-1 | **포인트 경제** | 가입 시 **5,000 P** 지급. 추가 획득은 **경매를 열어 낙찰시키는 것**뿐 | [데이터 모델](../데이터-모델-명세.md) §10 |
| 3 | **사연 삭제 (마감 전)** | **전액 반환 + 재작성 허용** | [F3](./F3-사연-작성-입찰.md) 3.4 |
| 4 | **경매 삭제** | **사연이 1건이라도 있으면 삭제 불가** | [F1](./F1-경매-등록.md) 3.6 |
| 5 | **사연 삭제 (마감 후)** | **낙찰 사연 불가 / 미낙찰 사연 허용** | [F3](./F3-사연-작성-입찰.md) 3.4 |
| 6 | **알림** | 서비스 내 알림 목록 + 헤더 배지. **푸시 알림 없음** | [F9](./F9-알림.md) |

### 결정 간 맞물림

- **1 + 2** — 전액 반환이면 다들 상한(3,000 P)까지 올릴 유인이 생겨 기본 점수가 같아진다.
  그러면 공감(F4)이 유일한 변별력이 되고, 공감마저 같으면 **작성 시각**으로 갈린다.
  → **마감 전 랭킹 노출이 필수**다 (F5 3.2.1)
- **1 + 3** — 재작성하면 작성 시각이 밀려 동점에서 불리해진다.
  → 별도 제재 없이도 **갈아엎기가 억제**된다
- **6** — 푸시를 빼면서 신규 기능이 0개가 되어 PRD 7.3 E1이 예외 없이 성립한다
