# F8. 마이페이지

## 1. 기능명

**마이페이지 — 내 활동 통합 조회**

## 2. 기능 목적

**내가 걸어둔 것들이 지금 어떻게 됐는지**를 한 화면에서 본다.

- 내가 연 경매와 내가 쓴 사연을 **탭 전환만으로** 오간다
- 상세 정보는 담지 않는다. **목록이지 상세 화면이 아니다**

> **변경점** — 기존에는 '내 경매'와 '내 사연'이 모드에 따라 **번갈아 노출**됐다.
> 둘 다 보려면 헤더 토글을 바꿔야 했다.
> 이제 **탭 하나로 즉시 전환**한다. 이 화면이 곧 유형 통합의 결과다.

## 3. 동작 방식

### 3.1 화면 구성

```
┌──────────────────────────────┐
│  닉네임                       │
│  보유 포인트  5,000 P    ›    │  ← 누르면 포인트 내역
│  배송지  등록됨          ›    │  ← 누르면 배송지 수정
│                              │
│  로그아웃                     │  ← F10 3.7
├──────────────────────────────┤
│  [ 내 경매 ] [ 내 사연 ] [ 찜 ]│  ← 탭
├──────────────────────────────┤
│  목록                         │
└──────────────────────────────┘
```

**별도 메뉴 페이지를 두지 않는다.** 프로필 영역과 탭 3개가 전부다.

**로그아웃은 프로필 행과 탭 사이에 둔다.** 탭 내용 아래에 두면 탭마다 앉는 자리가
달라져 어디에도 속하지 않아 보인다. 값도 화살표도 없다 — 이동이 아니라 동작이다.
경고색을 쓰지 않는다. 레드는 마감 임박·오류·필수 입력 전용이다 (PRD B3).

### 3.2 프로필 영역

| 항목 | 내용 |
|---|---|
| 프로필 이미지 · 닉네임 | 소셜 계정 정보 |
| **보유 포인트** | 숫자를 누르면 포인트 내역으로 이동 |
| **배송지** | `등록됨` / `미등록`. 누르면 등록·수정 화면 (F12) |
| **로그아웃** | 프로필 행 묶음 아래. 확인을 물은 뒤 종료한다 (F10 3.7) |

- 이메일은 표시하지 않는다. 화면에서 하는 일이 없다
- **역할 뱃지를 표시하지 않는다.** 사용자 유형 개념이 존재하지 않는다

### 3.3 탭 — 내 경매

내가 등록한 경매. **카드 한 장에 4개만 담는다.**

| 표시 | 내용 |
|---|---|
| 대표 이미지 | |
| 제목 | |
| 상태 | `진행중` · `마감 임박` · `낙찰됨` · `유찰` |
| 모인 사연 수 | `사연 5` |

진행중이면 남은 시간을 함께 보여준다.
**낙찰자 정보·포인트·순위는 담지 않는다.** 카드를 누르면 경매 상세에서 본다.

### 3.4 탭 — 내 사연

내가 사연을 쓴 경매. **카드 한 장에 3개만 담는다.**

| 표시 | 내용 |
|---|---|
| 경매 대표 이미지 | |
| 경매 제목 | |
| 상태 | `참여중` · `낙찰` · `탈락` |

진행중이면 남은 시간을 함께 보여준다.
**내 사연 내용·건 포인트·받은 공감·순위는 담지 않는다.** 경매 상세에서 본다.

> 마이페이지에서 알아야 할 것은 **"됐는지 안 됐는지"** 하나다.

### 3.5 탭 — 찜

찜한 경매 목록. 내 경매 탭과 같은 카드를 쓴다.
카드에서 바로 **찜 해제**할 수 있다.

### 3.6 포인트 내역

프로필의 보유 포인트를 눌러 진입한다. **시간순 목록 하나뿐이다.**

| 표시 | 내용 |
|---|---|
| 사유 | `입찰` · `반환` · `낙찰 수령` · `가입 축하` |
| 금액 | 차감은 **경고색**으로 `−`, 적립은 기본색으로 `+` |
| 시각 | |

필터·검색·기간 선택을 두지 않는다.

### 3.7 빈 상태

탭은 **항상 3개 모두 노출**한다. 내역이 없으면 안내와 다음 행동 경로를 함께 보여준다.

| 탭 | 안내 | 경로 |
|---|---|---|
| 내 경매 | "아직 등록한 경매가 없어요" | **경매 등록하기** |
| 내 사연 | "아직 작성한 사연이 없어요" | **경매 둘러보기** |
| 찜 | "찜한 경매가 없어요" | **경매 둘러보기** |

## 4. 예외 처리

| 상황 | 처리 |
|---|---|
| 비회원 진입 | 홈으로 이동시키고 로그인을 유도한다 |
| 로그인 세션 만료 | 홈으로 이동시킨다. 만료된 정보를 화면에 남기지 않는다 |
| 프로필 조회 실패 | 프로필 영역에만 에러와 재시도를 표시한다. **탭은 정상 동작**한다 |
| 보유 포인트 조회 실패 | 포인트 자리에만 에러를 표시한다. **0 P로 표시하지 않는다** |
| 특정 탭 조회 실패 | 해당 탭에만 에러와 재시도를 표시한다. 다른 탭은 영향받지 않는다 |
| **내역 없음과 조회 실패** | **서로 다른 화면으로 구분**한다. 조회 실패를 빈 상태로 표시하지 않는다 |
| 목록의 경매가 삭제됨 | 해당 항목을 제외해 표시한다. 목록이 깨지지 않아야 한다 |
| 프로필 이미지 로드 실패 | 기본 아바타로 대체한다 |
| 배송지 미등록 | `미등록`으로 표시하고 등록 화면으로 연결한다. **오류로 표시하지 않는다** |

## 5. 완료 조건

| # | 조건 |
|---|---|
| 1 | **탭 3개가 항상 노출된다.** 관계·활동 이력에 따른 필터링이 없다 |
| 2 | 한 계정에서 **내 경매와 내 사연을 탭 전환만으로** 오갈 수 있다. 페이지 이동이 없다 |
| 3 | 메뉴 구성에 `users.role`을 조회하지 않는다 |
| 4 | 프로필에 역할 뱃지가 표시되지 않는다 |
| 5 | **별도 메뉴 목록 페이지가 없다.** 프로필 영역 + 탭 3개가 전부다 |
| 6 | 카드에 담기는 정보가 **내 경매 4개 · 내 사연 3개**를 넘지 않는다 |
| 7 | 내역이 없는 탭에 **빈 상태 안내와 다음 행동 경로**가 표시된다 |
| 8 | 내역 없음과 조회 실패가 서로 다른 화면으로 구분된다 |
| 9 | 한 영역의 조회 실패가 다른 영역을 막지 않는다 |
