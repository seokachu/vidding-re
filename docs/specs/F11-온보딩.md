# F11. 온보딩

## 1. 기능명

**첫 방문자 온보딩**

## 2. 기능 목적

처음 온 사용자에게 **이 경매가 왜 다른지**를 이해시킨다.

- "돈이 아니라 사연으로 입찰한다"는 낯선 개념을 먼저 설명한다
- **낙찰 규칙**을 미리 알려 참여 후 혼란을 줄인다
- 설명을 건너뛰고 바로 둘러볼 수 있게 한다

## 3. 동작 방식

### 3.1 구성

슬라이드 3장으로 구성하며, 진행 표시와 건너뛰기를 함께 제공한다.

| 슬라이드 | 전달할 내용 |
|:---:|---|
| 1 | **사연으로 입찰하는 경매**라는 서비스 정체성 |
| 2 | 사연을 쓰고 공감을 받는 **참여 방식** |
| 3 | **낙찰 규칙** — 공감이 점수가 되어 낙찰자를 정한다 |

### 3.2 조작

| 요소 | 동작 |
|---|---|
| 다음 / 이전 | 슬라이드 이동 |
| 진행 표시 | 현재 위치 표시 |
| 건너뛰기 | 온보딩을 종료하고 홈으로 이동 |
| 마지막 슬라이드 | 시작하기 → 홈으로 이동 |

### 3.3 접근

- 로그인이 필요 없다 (F10 3.4)
- 비회원이 열람할 수 있다

### 3.4 문구 수정 — 필수

3번 슬라이드의 낙찰 규칙 설명에 **사용자 유형 용어가 남아 있다.**

| 현재 | 수정 |
|---|---|
| `일반 유저 + 판매자 좋아요 = 총점` | **`참여자 공감 + 주최자 공감 = 총점`** |

**함께 정리할 것**

- 서비스 전체에서 **판매자·구매자 표현을 제거**한다 (PRD C2)
- 온보딩에 **경매진행자/입찰참여자로 나뉜다는 설명이 있으면 삭제**한다
- 사용자를 두 유형으로 나누는 어떤 서술도 남기지 않는다

### 3.5 낙찰 규칙 안내 — 추가

확정된 정책을 온보딩 3번 슬라이드에 반영한다.

| 항목 | 안내 문구 |
|---|---|
| 공감 가중치 | 주최자의 공감은 **50 P**, 그 외 공감은 **10 P** |
| **동점 처리** | 같은 포인트일 땐 **먼저 작성한 사연**이 낙찰됩니다 |
| 포인트 정산 | 낙찰되지 않으면 **건 포인트를 돌려받습니다** |

> 낙찰 규칙은 참여 전에 알아야 공정하게 느껴진다.
> 특히 **동점 기준**은 마감 후에 처음 알게 되면 불만으로 이어진다 (F5 3.2.1).

### 3.6 색상

역할별 테마가 사라졌으므로 온보딩도 **블루 단일 테마**를 따른다.
레드는 마감 임박·경고 의미로만 사용한다.

## 4. 예외 처리

| 상황 | 처리 |
|---|---|
| 온보딩 도중 이탈 | 진행 상태를 저장하지 않는다. 다시 들어오면 처음부터 시작한다 |
| 슬라이드 이미지 로드 실패 | 텍스트만으로도 내용이 전달되어야 한다. 레이아웃이 무너지지 않는다 |
| 마지막 슬라이드에서 다음 클릭 | 홈으로 이동시킨다. 빈 슬라이드를 보여주지 않는다 |
| 첫 슬라이드에서 이전 클릭 | 이전 버튼을 노출하지 않거나 비활성 상태로 둔다 |
| 이미 로그인된 사용자가 진입 | 정상 노출한다. 온보딩은 로그인 여부와 무관하다 |
| 애니메이션 미지원 환경 | 애니메이션 없이도 내용과 조작이 정상 동작해야 한다 |

## 5. 완료 조건

| # | 조건 |
|---|---|
| 1 | 슬라이드 3장이 이동·건너뛰기와 함께 동작한다 |
| 2 | **`"일반 유저 + 판매자 좋아요 = 총점"` 문구가 존재하지 않는다** |
| 3 | 온보딩 전체에 **판매자·구매자 표현이 0건**이다 |
| 4 | 사용자를 두 유형으로 나누는 설명이 없다 |
| 5 | 공감 가중치(50 P / 10 P)가 안내된다 |
| 6 | **동점 기준(먼저 작성한 사연 우선)** 이 안내된다 |
| 7 | 미낙찰 시 포인트 반환이 안내된다 |
| 8 | 비회원이 로그인 없이 열람할 수 있다 |
| 9 | 블루 단일 테마로 표시되고, 레드가 경고 외 용도로 쓰이지 않는다 |
