# F11. 온보딩

## 1. 기능명

**첫 방문자 온보딩**

## 2. 기능 목적

처음 온 사용자에게 **이 경매가 왜 다른지**를 이해시킨다.

- "돈이 아니라 사연으로 입찰한다"는 낯선 개념을 먼저 설명한다
- **낙찰 규칙**을 미리 알려 참여 후 혼란을 줄인다
- 설명을 건너뛰고 바로 둘러볼 수 있게 한다

## 3. 동작 방식

### 3.1 구성

슬라이드 3장으로 구성하며, 진행 표시와 건너뛰기를 함께 제공한다.

| 슬라이드 | 전달할 내용 |
|:---:|---|
| 1 | **사연으로 입찰하는 경매**라는 서비스 정체성 |
| 2 | 사연을 쓰고 공감을 받는 **참여 방식** |
| 3 | **낙찰 규칙** — 공감이 점수가 되어 낙찰자를 정한다 |

### 3.2 조작

| 요소 | 동작 |
|---|---|
| 다음 / 이전 | 슬라이드 이동 |
| 진행 표시 | 현재 위치 표시 |
| 건너뛰기 | 온보딩을 종료하고 **로그인 화면**으로 이동 |
| 마지막 슬라이드 | 시작하기 → **로그인 화면**으로 이동 |

### 3.3 접근과 진입 시점

**서비스 입구(`/`)가 갈림길을 잡는다.** 화면을 그리지 않고 둘 중 하나로 보낸다.

```
로그인함   → 홈
로그아웃함 → 온보딩 → (다음 끝 · 건너뛰기) → 로그인 화면
```

온보딩이 하는 일은 "사연으로 입찰한다"는 낯선 개념을 이해시키는 것이므로
**가입을 결정하기 전에** 나와야 한다. 로그인 뒤에 보여주면 이미 결정한
사람에게 설명하는 셈이다.

- 로그인이 필요 없다 (F10 3.4). 주소로 직접 들어와도 언제든 볼 수 있다
- 로그인한 사용자는 **다시 보지 않는다.** 입구에서 홈으로 갈리기 때문이다

| 항목 | 내용 |
|---|---|
| 본 적 있는지 | **기록하지 않는다** (아래) |
| 출구 | **로그인 화면(`/auth/signup`).** 입구(`/`)로 되돌리면 로그아웃 상태에서 다시 온보딩으로 밀려 루프가 된다 |
| 로그인 오류 복귀 | `/?error=` 로 돌아온 경우 소개를 태우지 않고 로그인 화면으로 넘긴다. 로그인이 막힌 사람에게 필요한 것은 사유이지 서비스 설명이 아니다 |

**"봤는지"를 저장하지 않는 이유** — 로그아웃 상태로 입구에 오는 일 자체가
드물다. 둘러보기를 누른 사람은 `/main` 에 있고, 하단 탭 어디도 `/` 로 가지
않는다. 로그인하면 입구에서 홈으로 갈린다. 즉 다시 보게 되는 경우는 **로그아웃
직후 또는 주소를 직접 친 경우**뿐이고, 그마저 건너뛰기 한 번이면 지나간다.

그 드문 재노출 하나를 막으려면 로그인 전을 덮을 쿠키와 계정을 덮을 컬럼이
둘 다 필요하다. 값이 맞지 않는다.

> 한 번은 `users.onboarded_at` 으로 계정에 기록했다가 되돌렸다
> (`20260803000001` → `20260803000002`). 소개를 로그인 **뒤**에 보여준다는
> 전제 위에서 만든 장치였는데, 그 전제 자체가 순서가 뒤집힌 것이었다.

### 3.4 문구 수정 — 필수

3번 슬라이드의 낙찰 규칙 설명에 **사용자 유형 용어가 남아 있다.**

| 현재 | 수정 |
|---|---|
| `일반 유저 + 판매자 좋아요 = 총점` | **`참여자 공감 + 주최자 공감 = 총점`** |

**함께 정리할 것**

- 서비스 전체에서 **판매자·구매자 표현을 제거**한다 (PRD C2)
- 온보딩에 **경매진행자/입찰참여자로 나뉜다는 설명이 있으면 삭제**한다
- 사용자를 두 유형으로 나누는 어떤 서술도 남기지 않는다

### 3.5 낙찰 규칙 안내 — 추가

확정된 정책을 온보딩 3번 슬라이드에 반영한다.

| 항목 | 안내 문구 |
|---|---|
| 공감 가중치 | 주최자의 공감은 **50 P**, 그 외 공감은 **10 P** |
| **동점 처리** | 같은 포인트일 땐 **먼저 작성한 사연**이 낙찰됩니다 |
| 포인트 정산 | 낙찰되지 않으면 **건 포인트를 돌려받습니다** |

> 낙찰 규칙은 참여 전에 알아야 공정하게 느껴진다.
> 특히 **동점 기준**은 마감 후에 처음 알게 되면 불만으로 이어진다 (F5 3.2.1).

### 3.6 색상

역할별 테마가 사라졌으므로 온보딩도 **블루 단일 테마**를 따른다.
레드는 마감 임박·경고 의미로만 사용한다.

## 4. 예외 처리

| 상황 | 처리 |
|---|---|
| 온보딩 도중 이탈 | 진행 상태를 저장하지 않는다. 다시 들어오면 처음부터 시작한다 |
| 슬라이드 이미지 로드 실패 | 텍스트만으로도 내용이 전달되어야 한다. 레이아웃이 무너지지 않는다 |
| 마지막 슬라이드에서 다음 클릭 | 로그인 화면으로 이동시킨다. 빈 슬라이드를 보여주지 않는다 |
| 첫 슬라이드에서 이전 클릭 | 이전 버튼을 노출하지 않거나 비활성 상태로 둔다 |
| 이미 로그인된 사용자가 진입 | 정상 노출한다. 온보딩은 로그인 여부와 무관하다 |
| 애니메이션 미지원 환경 | 애니메이션 없이도 내용과 조작이 정상 동작해야 한다 |
