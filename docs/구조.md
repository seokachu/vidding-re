## 관계 판정

**모든 권한 판정은 여기 하나를 거친다** (`docs/specs/00-관계-판정.md`).

```ts
import { getAuctionContext } from "@/lib/relationship.server";

const result = await getAuctionContext(auctionId);
if (!result.ok) {
  // NOT_FOUND → 404 / ERROR → 에러 화면 + 재시도. 액션 버튼은 하나도 노출하지 않는다
}

const { relationship, can, isClosed } = result.context;

can.writeEpisode   // 방문자 + 진행중
can.placeBid       // 참여자 + 진행중
can.like           // 주최자·참여자·방문자 + 진행중
can.favorite       // 참여자·방문자 (마감돼도 가능 — 개인 북마크다)
can.editAuction    // 주최자 + 진행중
can.deleteAuction  // 주최자 + 사연 0건
can.chat           // 마감 + 낙찰 확정 + (주최자 | 낙찰자)
```

`relationship` 이 `null` 이면 **판정하지 못한 것**이다. 방문자로 취급하지 말고
버튼을 비활성으로 두고 "잠시 후 다시 시도해주세요"를 띄운다.

> `users.role` 을 조회하는 코드는 0건이어야 한다. 그런 컬럼은 스키마에 없다.

## 화면 껍데기

**탭 4개** (홈 · 탐색 · 알림 · 마이) — 헤더 + 하단 네비가 붙는다.

```tsx
import { TabShell } from "@/components/layout/tab-shell";

export default async function Page() {
  return <TabShell title="경매 현황">{/* 내용 */}</TabShell>;
}
```

`title` 을 비우면 헤더에 로고를 그린다 (홈).
읽지 않은 알림 점은 `TabShell` 이 알아서 찍는다.

**그 외 화면** — 상단 바를 직접 쓴다.

```tsx
import { TopAppBar } from "@/components/ui";

<TopAppBar title="경매 상세" action={<button>…</button>} />
```

> `TabShell` 은 서버 컴포넌트 전용이다. 클라이언트 컴포넌트에서 import 하면 빌드가 깨진다.

## 토큰

`.pen` 의 문서 변수가 `globals.css` 의 `@theme` 에 그대로 들어가 있다.

| 종류 | 예 |
|---|---|
| 색 | `bg-accent` `text-text-secondary` `border-border` `bg-warning-subtle` |
| 글자 | `text-title` `text-body` `text-caption` `text-label` `text-micro` |
| 줄간 | `leading-tight` `leading-snug` `leading-normal` `leading-relaxed` |
| 반경 | `rounded-sm`(6) `rounded-md`(10) `rounded-lg`(14) `rounded-full` |
| 여백 | `px-gutter`(20) · 나머지는 Tailwind 기본 4px 배수 |

**임의 색을 쓰지 않는다.** 필요한 색이 없으면 `.pen` 을 먼저 고친다.
레드(`warning`)는 **마감 임박과 경고에만** 쓴다.

## 지켜야 할 것

| 항목 | 이유 |
|---|---|
| `src/components/ui/` 는 `.pen` 의 `03` 을 그대로 옮긴 곳이다 | 여기에 컴포넌트를 더하려면 **`.pen` 에 먼저 그린다.** 코드에만 있는 컴포넌트가 생기면 제출물의 컴포넌트 수가 어긋난다 |
| `package.json` 에 의존성을 추가하지 않는다 | 락파일 충돌 |
| **Realtime 구독 전에 `authorizeRealtime()`** | `postgres_changes` 의 RLS 판정은 채널 join 순간 한 번뿐인데 토큰이 실리는 것은 비동기다. 빠뜨리면 익명으로 붙어 **상태는 `SUBSCRIBED` 인데 이벤트가 하나도 오지 않는다** |
| 재시도 화면은 `ErrorState` 를 그냥 쓴다 | 기본 동작이 화면 새로고침이다. `router.refresh()` 래퍼를 따로 만들지 않는다 |
| 포인트·낙찰·공감은 RPC 로만 바꾼다 | 잔액과 원장이 한 트랜잭션에서 함께 움직여야 한다 (§4) |
| 빈 상태와 조회 실패를 구분한다 | `EmptyState` / `ErrorState`. 실패를 빈 목록으로 위장하지 않는다 |
| 남은 시간은 `formatTimeLeft` 를 쓴다 | 마감 시각이 지났으면 크론 처리 전이라도 마감으로 보여야 한다 |
